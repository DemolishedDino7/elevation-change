Official team logos for the Elevation Index.

Save each school's official primary athletics logo (PNG, transparent
background, roughly square, at least 200x200) in this folder with
exactly these filenames:

  AFA.png   Air Force            NDSU.png  North Dakota State
  HAW.png   Hawai'i              NIU.png   Northern Illinois
  NEV.png   Nevada               SJSU.png  San Jose State
  UNM.png   New Mexico           UNLV.png  UNLV
  UTEP.png  UTEP                 WYO.png   Wyoming
  BSU.png   Boise State          CSU.png   Colorado State
  FRES.png  Fresno State         ORST.png  Oregon State
  SDSU.png  San Diego State      TXST.png  Texas State
  USU.png   Utah State           WSU.png   Washington State
  NMSU.png  New Mexico State     SAC.png   Sacramento State

Most schools publish these on their athletics site under "Brand",
"Logos", "Style Guide" or "Media". If a file is missing the site
falls back automatically, so you can add them a few at a time.
